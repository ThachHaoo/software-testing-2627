> **Quy tắc viết**
> - `ia`: đúng 1 mã IA-01 / IA-02 / IA-03 / IA-04.
> - `man_hinh`: trong phạm vi checklist.
> - `muc_kiem_tra`: 1 điều cần kiểm, viết trung lập (không viết sẵn kết quả lỗi).
> - `can_cu`: điều khoản đặc tả `FR-xx (README.md:dòng)` / heuristic (tên + số) / checklist theo control trong slide / WCAG SC / giả định mới do SV chốt (ghi ở mục Giả định).
> - `loai_nguon`: SRS / Control / Heuristic — lấy theo nguồn đứng đầu `can_cu`.
> - `tien_dieu_kien`: (nếu có) dữ liệu/cấu hình cần trước khi kiểm.
> - `expected`: quan sát được ở đâu, bằng cách nào + một câu "Fail nếu …".
> - `nen_tang`: mã nền tảng; nền tảng nào N/A thì ghi kèm mã giả định, vd `P1, P2 (P3 N/A theo NA1)`.
> - `uu_tien`: Mandatory / Optional.
> - `luc_them`: trước khi chạy / trong lúc chạy Px (ghi trung thực).
> - `ly_do_AI_bo_sot.loai`: prompt / giới hạn model / đặc điểm giao diện / khác.
> - `ly_do_AI_bo_sot.giai_thich`: 1–3 câu, lời của SV.
